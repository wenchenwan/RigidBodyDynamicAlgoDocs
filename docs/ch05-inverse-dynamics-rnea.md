# 第 5 章 逆动力学 (Inverse Dynamics) —— RNEA

> **一句话概括**：给定 $q,\dot q,\ddot q$ 求 $\tau$。
> 递推牛顿-欧拉算法 (Recursive Newton-Euler Algorithm, RNEA) 用
> **一趟外推 + 一趟内推**，以 $O(n)$ 的代价解决它。

> ★ 核心算法之一。RNEA 是全书最简洁、也是实践中用得最多的算法。

## 本章定位

前四章铺垫完毕，从这章开始出算法。RNEA 是最简单的一个，
而且它还是后面几个算法的**构件**（用它可以算 $C$、可以逐列算 $H$、
可以做混合动力学）。**吃透 RNEA，全书就成功了一半。**

## 前置依赖

- 第 2 章：$\mathbf{v},\mathbf{a}$ 的合成、$X$ / $X^*$、$I$、
  $\mathbf{f}=I\mathbf{a}+\mathbf{v}\times^*I\mathbf{v}$
- 第 3 章：$\tau_i = S_i^{\mathsf T}\mathbf{f}_i$
- 第 4 章：`model` 数据结构、`jcalc`、$\lambda(i)<i$

## 核心思路

RNEA 的逻辑只有两句话：

1. **外推 (outward pass, `for i = 1 to N`)**：
   运动学信息从根流向叶。已知父的 $\mathbf{v},\mathbf{a}$ 和关节运动，
   算出每个刚体的 $\mathbf{v}_i,\mathbf{a}_i$，
   再由单刚体运动方程算出**让该刚体产生这个加速度所需的净力** $\mathbf{f}_i$。

2. **内推 (inward pass, `for i = N to 1`)**：
   力信息从叶流向根。每个刚体所需的净力由它自己的关节和所有下游关节共同提供，
   所以把子节点的力累加到父节点上，同时用 $\tau_i = S_i^{\mathsf T}\mathbf{f}_i$
   把 6D 力投影出关节力矩。

**为什么是 $O(n)$**：每个刚体只被访问常数次，没有任何全局求解。

## 算法

```
────────────────────────────────────────────────────────────────
RNEA:  τ = ID(model, q, q̇, q̈,  [f^x])
输入:  model, 关节位置 q、速度 q̇、加速度 q̈，可选外力 f^x（世界系）
输出:  关节广义力 τ
复杂度: O(n)
────────────────────────────────────────────────────────────────

  v₀ = 0
  a₀ = −a_g                          ← 重力技巧，见下

  # ---- 外推：运动学 + 每个刚体所需净力 ----
  for i = 1 to N_B:
      [X_J, S_i, v_J, c_J] = jcalc(jtype(i), q_i, q̇_i)
      ⁱX_λ(i) = X_J · X_T(i)

      v_i = ⁱX_λ(i) · v_λ(i) + v_J
      a_i = ⁱX_λ(i) · a_λ(i) + S_i · q̈_i + c_J + v_i × v_J

      f_i = I_i · a_i  +  v_i ×* I_i · v_i  −  ⁱX₀* · f^x_i

  # ---- 内推：力的累加与投影 ----
  for i = N_B to 1:
      τ_i = S_iᵀ · f_i
      if λ(i) ≠ 0:
          f_λ(i) = f_λ(i) + λ⁽ⁱ⁾X_i* · f_i
────────────────────────────────────────────────────────────────
```

其中 $\mathbf{v}_J = S_i\dot q_i$，$\mathbf{c}_J = \dot S_i\dot q_i$
（常见关节为 0）。

### 逐行注解

| 行 | 在做什么 | 依据 |
|---|---|---|
| `a₀ = −a_g` | 重力技巧 | 见下节 |
| `v_i = X·v_λ + v_J` | 速度合成，**纯线性** | 第 2 章：$\mathbf{v}_2=\mathbf{v}_1+\mathbf{v}_{\text{rel}}$ |
| `a_i = X·a_λ + S q̈ + c_J + v_i × v_J` | 加速度合成 | 第 2 章：$\mathbf{a}_2=\mathbf{a}_1+\mathbf{a}_{\text{rel}}+\mathbf{v}_1\times\mathbf{v}_{\text{rel}}$ |
| `f_i = I a + v ×* I v` | 单刚体运动方程 | 第 2 章 |
| `− ⁱX₀* f^x_i` | 减去外力 | 外力已经提供了一部分，关节就少出一部分 |
| `τ_i = S_iᵀ f_i` | 投影出关节力矩 | 第 3 章：约束力被 $S^{\mathsf T}$ 消掉 |
| `f_λ += X* f_i` | 力沿树向上传递 | 作用-反作用 |

> ⚠️ 注意 `a_i` 那一行里的交叉项是 $\mathbf{v}_i\times\mathbf{v}_J$
> （用**已经算好的** $\mathbf{v}_i$，不是 $\mathbf{v}_{\lambda(i)}$），
> 而且**没有系数 2**。经典记法里的科氏项 $2\omega\times v$ 在这里
> 被空间加速度的定义吸收掉了（见第 2 章 §2.8）。这是最常见的实现 bug 之一。

## 重力技巧 (Gravity Trick)

**做法**：不给每个刚体加重力 $m_i g$，而是令基座的加速度为
$\mathbf{a}_0 = -\mathbf{a}_g$（$\mathbf{a}_g$ 是重力加速度对应的空间加速度）。

**为什么对**：这是**等效原理**的直接应用。让整个系统"向上加速"$-g$，
在非惯性系里产生的惯性力场，与均匀重力场**完全等价**。

**为什么划算**：
- 不需要在外推里为每个刚体单独构造重力向量并做坐标变换
- 重力自动沿着已有的加速度递推链传播，**一行代码，零额外开销**
- 数值上也更好：重力和其他加速度用同一条路径传播，不会产生额外的舍入路径

**副作用（务必注意）**：这么做之后 $\mathbf{a}_i$ **不再是刚体的真实加速度**，
而是"真实加速度 $-\mathbf{a}_g$"。如果你要输出真实加速度（比如做可视化或
和加速度计对比），必须加回 $\mathbf{a}_g$。

## 外力的处理

$\mathbf{f}^x_i$ 表示施加在 body $i$ 上的外力（接触力、推力、空气阻力……），
通常在**世界坐标系**中给出，所以要先变换到 body $i$ 的坐标系：
${}^{i}X_0^*\,\mathbf{f}^x_i$。

符号是**减号**：外力已经帮忙提供了一部分所需净力，关节需要出的力相应减少。

**不需要外力时**（最常见情况），整项省略即可，能省下 $N_B$ 次 $6\times6$ 变换。

## RNEA 的四大用法

RNEA 的价值远不止"算力矩"。它是一台**通用计算引擎**：

### 用法 1：计算力矩控制 (Computed Torque Control)

$$
\tau = \mathrm{ID}\big(q,\ \dot q,\ \ddot q_{d} + K_d(\dot q_d - \dot q) + K_p(q_d - q)\big)
$$

这是机器人控制里最标准的做法：用 RNEA 做前馈补偿，PD 做反馈。

### 用法 2：计算偏置力 $C$

$$
C(q,\dot q) = \mathrm{ID}(q,\ \dot q,\ \mathbf{0})
$$

把 $\ddot q$ 置零跑一遍。**FD 的第一步就是这个**（第 6 章要用）。

### 用法 3：只算重力项

$$
g(q) = \mathrm{ID}(q,\ \mathbf{0},\ \mathbf{0})
$$

速度和加速度都置零，剩下的只有重力。用于重力补偿控制。

### 用法 4：逐列构造 $H$ —— "$n$ 次 RNEA 法"

$$
H_{\cdot j} = \mathrm{ID}(q,\ \mathbf{0},\ e_j) - \mathrm{ID}(q,\ \mathbf{0},\ \mathbf{0})
$$

（$e_j$ 是第 $j$ 个单位向量。若同时忽略重力，第二项为零。）

跑 $n$ 次 RNEA 就能得到整个 $H$，总代价 $O(n^2)$。

> 这个办法**能用但不划算**——CRBA（第 6 章）做同一件事快好几倍，
> 因为它复用了子树的复合惯性。不过这个技巧在只需要 $H$ 的几列时很有用，
> 也是理解"$H$ 到底是什么"的好方式：**$H$ 的第 $j$ 列 = 只让关节 $j$ 有单位加速度、
> 其余关节加速度为零时，各关节需要出的力。**

## 复杂度与代价

| 指标 | 值 |
|---|---|
| 渐近复杂度 | $O(n)$ |
| 遍历次数 | 2 趟（1 外推 + 1 内推） |
| 是否需要解方程 | **否**，纯递推 |
| 精确浮点运算次数 | 〔待填，见第 10 章代价表〕 |

RNEA 是**已知最快的逆动力学算法**，几乎没有改进空间。
后续研究主要集中在实现层面（SIMD、代码生成、稀疏特化）。

## 易错点与陷阱

1. **加速度交叉项写成 $\mathbf{v}_{\lambda(i)}\times\mathbf{v}_J$**。
   必须用 $\mathbf{v}_i$（本体的、已合成的速度）。
2. **给交叉项加了系数 2**。空间记法里没有那个 2（见第 2 章 §2.8）。
3. **重力符号搞反**。是 $\mathbf{a}_0 = -\mathbf{a}_g$，不是 $+\mathbf{a}_g$。
   症状：算出来的重力补偿力矩方向全反。
4. **$\times$ 和 $\times^*$ 用混**。`f_i` 那行用的是 $\times^*$（作用在力上），
   `a_i` 那行用的是 $\times$（作用在运动上）。
5. **忘了 $\mathbf{v}_0=\mathbf{0}$ 的初始化**，或对 $\lambda(i)=0$ 的刚体特殊处理写错。
   把 body 0 的 $\mathbf{v}_0=\mathbf{0}$、$\mathbf{a}_0=-\mathbf{a}_g$ 显式初始化，
   统一的循环体就能自动处理根节点，不需要 if 分支。
6. **内推时忘记 `f_λ(i) +=` 的累加语义**。有多个子节点的刚体（分支处）
   必须把所有子节点的力都加上，写成赋值 `=` 会丢掉除最后一个之外的所有分支。
7. **外力坐标系没转换**。$\mathbf{f}^x$ 一般在世界系给出，直接用会错得离谱。

## 调试建议

- **能量检验**：无外力时用 RNEA 算出的 $\tau$ 回代，
  验证 $\tau^{\mathsf T}\dot q$ 与动能变化率一致。
- **与 ABA 互验**：ABA 算出 $\ddot q$ 后喂回 RNEA，应该得回原来的 $\tau$
  （见 [`docs/00-roadmap.md`](00-roadmap.md) 第五节）。
- **静态检验**：令 $\dot q=\ddot q=0$，RNEA 的输出应等于重力力矩，
  可以用手算的静力平衡验证简单机构。
- **单刚体检验**：$N_B=1$、自由关节，退化成单刚体的牛顿-欧拉方程，可解析验证。
