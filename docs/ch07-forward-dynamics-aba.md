# 第 7 章 正动力学·传播法 (Forward Dynamics — Propagation Methods) —— ABA

> **一句话概括**：不构造 $H$，直接用**三趟递推**求出 $\ddot q$。
> 铰接体算法 (Articulated-Body Algorithm, ABA)，复杂度 $O(n)$。

> ★ 核心算法之一，也是本书最精妙的一个。

## 本章定位

第 6 章的路线是"造矩阵 + 解方程"。本章反其道而行：
**把"解方程"这件事本身也变成沿树的递推**。
代价从 $O(n^3)$ / $O(nd^2)$ 降到 $O(n)$，是本书理论上的高峰。

## 核心概念：铰接体惯性 (Articulated-Body Inertia)

这是全章的关键，也是唯一需要"想通"的地方。

### 问题

考虑 body $i$ 及其**整个子树**，但子树里的关节**是自由的**（不是焊死的）。
现在从外面对 body $i$ 施加一个空间力 $\mathbf{f}$，问 body $i$ 会产生多大加速度 $\mathbf{a}$？

### 答案

$$
\boxed{\ \mathbf{f} = I^{A}_{i}\,\mathbf{a} + \mathbf{p}^{A}_{i}\ }
$$

- $I^{A}_{i}$：**铰接体惯性**——子树对 body $i$ 表现出的"等效惯性"
- $\mathbf{p}^{A}_{i}$：**偏置力 (bias force)**——即使 $\mathbf{a}=0$，
  子树内部的速度效应（离心/科氏）和已知的关节力矩仍会向 body $i$ 传回一个力

### 三个惯性概念的对比（务必分清）

| 概念 | 记号 | 子树关节状态 | 关系式 |
|---|---|---|---|
| 刚体惯性 | $I_i$ | 只考虑 body $i$ 自己 | $\mathbf{f}=I\mathbf{a}+\mathbf{v}\times^*I\mathbf{v}$ |
| 复合刚体惯性 | $I^{c}_i$ | **焊死**（第 6 章） | $\mathbf{f}=I^c\mathbf{a}+\dots$ |
| 铰接体惯性 | $I^{A}_i$ | **自由活动**（本章） | $\mathbf{f}=I^{A}\mathbf{a}+\mathbf{p}^{A}$ |

**直观对比**：
- 推一个**焊死**的机械臂 → 感觉到 $I^c$（很重）
- 推一个**关节松开**的机械臂 → 感觉到 $I^A$（轻得多，因为下游会自己甩开）

在能量意义上 $I^{A}\preceq I^{c}$：关节松开只会让系统"更容易被推动"。

### 为什么必须有偏置项 $\mathbf{p}^A$

因为**关系不是齐次线性的**。即使 body $i$ 的加速度为零，
子树里的连杆仍在运动（有离心力、科氏力），关节上也可能有已知的驱动力矩 $\tau_j$，
这些都会通过关节传回一个力。$\mathbf{p}^A$ 就是这一部分。

对比第 6 章：那里 $\mathbf{f}=I^c\mathbf{a}+\dots$ 的偏置部分被 RNEA 分开算成了 $C$；
这里因为要一趟做完，必须把偏置显式带在递推里。

### 递推关系（本章的核心推导）

设 body $i$ 有子节点 $j$。子节点向父节点贡献的"等效惯性"和"等效偏置力"是：

$$
I^{a}_{j} = I^{A}_{j} - U_{j}D_{j}^{-1}U_{j}^{\mathsf T},
\qquad
\mathbf{p}^{a}_{j} = \mathbf{p}^{A}_{j} + I^{a}_{j}\mathbf{c}_{j} + U_{j}D_{j}^{-1}u_{j}
$$

其中

$$
U_{j} = I^{A}_{j}S_{j},\qquad
D_{j} = S_{j}^{\mathsf T}U_{j} = S_j^{\mathsf T}I^A_j S_j,\qquad
u_{j} = \tau_{j} - S_{j}^{\mathsf T}\mathbf{p}^{A}_{j}
$$

然后

$$
I^{A}_{i} \mathrel{+}= {}^{i}X_{j}^{*}\,I^{a}_{j}\,{}^{j}X_{i},
\qquad
\mathbf{p}^{A}_{i} \mathrel{+}= {}^{i}X_{j}^{*}\,\mathbf{p}^{a}_{j}
$$

> 💡 **认出这个结构**：$I^{A}-UD^{-1}U^{\mathsf T}$ 是一个 **Schur 补**。
> 它在做的事情正是"**把关节 $j$ 的自由度消去 (eliminate)**"——
> 因为 $\ddot q_j$ 是未知的、由方程决定的，就把它从方程里解出来代回去。
>
> 这解释了 ABA 的本质：**它就是在树结构上做高斯消元**。
> 第 6 章是先把 $H$ 组装出来再消元，ABA 是**边组装边消元**，
> 于是永远不需要把整个 $H$ 存下来——这才是 $O(n)$ 的来源。
>
> $D_j = S_j^{\mathsf T}I^A_jS_j$ 就是消元时的**主元 (pivot)**，
> $I^A$ 正定保证了 $D_j>0$，所以 ABA **无需选主元**，数值上天然稳定。

## 算法：ABA

```
────────────────────────────────────────────────────────────────
ABA:  q̈ = FDab(model, q, q̇, τ, [f^x])
输入:  model, q, q̇, 关节力 τ，可选外力 f^x
输出:  关节加速度 q̈
复杂度: O(n)
────────────────────────────────────────────────────────────────

# ═══ 第 1 趟：外推 —— 速度、偏置项、初始化 ═══
  v₀ = 0
  for i = 1 to N_B:
      [X_J, S_i, v_J, c_J] = jcalc(jtype(i), q_i, q̇_i)
      ⁱX_λ(i) = X_J · X_T(i)

      v_i   = ⁱX_λ(i) · v_λ(i) + v_J
      c_i   = c_J + v_i × v_J                    # 偏置加速度
      I^A_i = I_i                                # 初始化为刚体惯性
      p^A_i = v_i ×* I_i · v_i − ⁱX₀* · f^x_i    # 初始化偏置力

# ═══ 第 2 趟：内推 —— 铰接体惯性的传播（消元） ═══
  for i = N_B to 1:
      U_i = I^A_i · S_i
      D_i = S_iᵀ · U_i
      u_i = τ_i − S_iᵀ · p^A_i

      if λ(i) ≠ 0:
          I^a = I^A_i − U_i · D_i⁻¹ · U_iᵀ            # Schur 补
          p^a = p^A_i + I^a · c_i + U_i · D_i⁻¹ · u_i

          I^A_λ(i) = I^A_λ(i) + λ⁽ⁱ⁾X_i* · I^a · ⁱX_λ(i)
          p^A_λ(i) = p^A_λ(i) + λ⁽ⁱ⁾X_i* · p^a

# ═══ 第 3 趟：外推 —— 回代求加速度 ═══
  a₀ = −a_g                                       # 重力技巧，同 RNEA
  for i = 1 to N_B:
      a' = ⁱX_λ(i) · a_λ(i) + c_i                 # 若关节加速度为零时的加速度
      q̈_i = D_i⁻¹ · (u_i − U_iᵀ · a')
      a_i = a' + S_i · q̈_i
────────────────────────────────────────────────────────────────
```

### 为什么必须是三趟

这是理解 ABA 的关键问题，值得想清楚：

| 趟 | 方向 | 算什么 | 为什么不能合并 |
|---|---|---|---|
| 1 | 外推 | $\mathbf{v}_i$、$\mathbf{c}_i$、$\mathbf{p}^A$ 初值 | 速度只依赖父节点 → **必须外推** |
| 2 | 内推 | $I^A$、$\mathbf{p}^A$、$U,D,u$ | 铰接体惯性依赖**整个子树** → **必须内推** |
| 3 | 外推 | $\ddot q_i$、$\mathbf{a}_i$ | 加速度依赖父节点的加速度 → **必须外推** |

方向是"外-内-外"，交替了两次，所以**三趟是下界，无法压缩成两趟**。
（对比 RNEA：只需"外-内"两趟，因为 $\ddot q$ 是已知输入。
**ABA 比 RNEA 多的那一趟，本质上就是在"解方程"。**）

## 复杂度与代价

| 指标 | 值 |
|---|---|
| 渐近复杂度 | $O(n)$ |
| 遍历次数 | 3 趟 |
| 是否需要解方程 | 只需解 $n_i\times n_i$ 的小系统（1-DoF 关节就是一次除法） |
| 精确浮点运算次数 | 〔待填，见第 10 章代价表〕 |

**$D_i^{-1}$ 不是矩阵求逆**：对 1 自由度关节，$D_i$ 是**标量**，$D_i^{-1}$ 就是倒数。
只有球关节（$3\times3$）和自由关节（$6\times6$）才需要真的解小系统。
实现时建议对 1-DoF 关节特化，能省掉可观开销。

## ABA vs CRBA

| 维度 | ABA | CRBA + 分解 |
|---|---|---|
| 复杂度 | $O(n)$ | $O(nd^2)$ ~ $O(n^3)$ |
| 常数因子 | **大** | 小 |
| 交叉点 | $n\gtrsim 9$ 时 ABA 胜〔待核对具体数值〕 | $n\lesssim 9$ 时 CRBA 胜 |
| 能否得到 $H$ | ❌ 不能 | ✅ 能 |
| 利用分支稀疏性 | 部分（自然的树递推） | ✅ 显式利用，浅树极快 |
| 内存 | $O(n)$，每个刚体一个 $6\times6$ | $O(n^2)$ 存 $H$ |
| 数值稳定性 | 好（$D_i>0$，无需选主元） | 好（Cholesky） |
| 实现难度 | 中（三趟，递推关系需推导） | 低（构造 + 调库分解） |
| 加约束/接触 | 困难，需要专门扩展 | 容易，直接进 KKT |

**实践建议**：
- 6/7 轴机械臂仿真 → CRBA 往往更快，而且顺便拿到 $H$
- 人形/四足（$n\approx 20\text{–}40$，$d$ 小）→ 两者都可，看是否需要 $H$
- 长链（绳索、软体离散化，$n>50$）→ ABA
- **需要接触约束** → 优先 CRBA 路线（KKT 系统更自然）

## 易错点与陷阱

1. **$\mathbf{p}^{a}$ 里的 $I^{a}\mathbf{c}_i$ 项漏掉**。这是最常见的 ABA bug。
   注意用的是 $I^{a}$（Schur 补之后的），**不是** $I^{A}$。
   症状：静态时正确，一动起来就错。
2. **第 3 趟里的 $\mathbf{a}'$ 忘了加 $\mathbf{c}_i$**。
3. **$\mathbf{c}_i$ 在第 1 趟算、第 3 趟用**，中间要存着。
   如果为了省内存在第 3 趟重算，注意 $\mathbf{v}_i$ 也得存。
4. **$U,D,u$ 在第 2 趟算、第 3 趟用**，同样要存。
5. **$X$ / $X^*$ 用混**。$I^a$ 用三明治 $X^*I^aX$，$\mathbf{p}^a$ 是力向量用 $X^*$。
6. **$D_i$ 接近零**。理论上 $I^A$ 正定 ⟹ $D_i>0$。
   如果 $D_i\approx0$，说明模型有问题（零惯量连杆、$S$ 退化）。加断言。
7. **重力技巧的位置**。$\mathbf{a}_0=-\mathbf{a}_g$ 放在**第 3 趟**开头，
   不是第 1 趟——第 1 趟只算速度，没有加速度。

## 调试建议

- **RNEA 互验（最有效）**：
  ```
  q̈ = ABA(q, q̇, τ)
  τ' = RNEA(q, q̇, q̈)
  assert ‖τ − τ'‖ ≈ 0
  ```
  两个算法完全独立，几乎不可能同时错成一致。**这是 ABA 唯一必须做的测试。**
- **与 CRBA 路线对照**：$\ddot q_{\text{ABA}}$ 应等于 $H^{-1}(\tau-C)$。
- **能量守恒**：无驱动、无外力时长时间仿真，总能量应只有积分器引起的缓慢漂移。
- **自由落体**：单刚体 + 自由关节，$\tau=0$，加速度应恰为 $\mathbf{a}_g$。
- **静止检验**：$\dot q=0$、$\tau = g(q)$（重力补偿），$\ddot q$ 应为零。
